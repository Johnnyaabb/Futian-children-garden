# 图标说明

TabBar 需要以下图标文件（PNG格式，建议 81x81px）：

- home.png / home-active.png      （今日菜单）
- cart.png / cart-active.png      （购物车）
- order.png / order-active.png    （我的订单）
- merchant.png / merchant-active.png  （商家管理）

可从以下途径获取：
1. 阿里巴巴图标库 https://www.iconfont.cn/
2. 使用真实项目时替换为品牌图标

**开发调试时**：微信开发者工具对缺失的 tabBar 图标不报错，可先用任意 PNG 占位。
